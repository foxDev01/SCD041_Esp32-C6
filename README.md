# SCD41 Монитор на ESP32-C6

Прошивка для ESP32-C6: измерения CO₂, температуры и влажности датчиком **Sensirion SCD41**,
веб-интерфейс для настройки и калибровки, публикация данных в **MQTT**.

## Возможности

- 📊 Измерение CO₂ (ppm), температуры (°C) и влажности (%) каждые 2 секунды
- 🌐 Веб-интерфейс на встроенном сервере (порт 80):
  - дашборд с текущими показаниями и цветовой индикацией уровня CO₂
  - настройка Wi-Fi
  - настройка MQTT
  - калибровка датчика
- 📡 Режим точки доступа (AP) для первичной настройки, если подключиться к Wi-Fi не удалось
- 💾 Хранение настроек (Wi-Fi, MQTT, ASC) в NVS через `Preferences` — переживают перезагрузку
- 📨 Публикация данных в MQTT (JSON) раз в 10 секунд, с автоматическим переподключением
- 🔧 Калибровка: ASC, калибровка свежим воздухом (400 ppm), принудительная калибровка (FRC),
  заводской сброс, перезапуск датчика

## Железо и подключение

- Плата: **ESP32-C6-DevKitC-1**
- Датчик: **Sensirion SCD41** (I²C)

| SCD41 | ESP32-C6 |
|-------|----------|
| SDA   | GPIO 19  |
| SCL   | GPIO 20  |
| VCC   | 3.3V     |
| GND   | GND      |

Пины I²C заданы в `src/main.cpp` (`I2C_SDA`, `I2C_SCL`).

## Сборка и прошивка

Проект собирается в [PlatformIO](https://platformio.org/).

```bash
# сборка
pio run

# прошивка и монитор порта
pio run -t upload
pio device monitor
```

Последовательный порт: **115200** бод.

## Настройка Wi-Fi (секреты)

Учётные данные Wi-Fi задаются не в коде, а через `build_flags`, чтобы не перепрошивать
устройство при смене сети. Для этого создайте файл `secrets.ini` в корне проекта
(он в `.gitignore`) на основе `secrets_example.ini`:

```ini
[env]
build_flags =
	-DWIFI_SSID="MyNetwork"
	-DWIFI_PASSWORD="MyPassword"
```

`platformio.ini` подключает его автоматически через `extra_configs = secrets.ini`.

Если флаги не заданы или сеть недоступна, используются настройки, сохранённые через
веб-интерфейс. Если подключиться не удалось — ESP32 поднимает точку доступа:

- **SSID:** `SCD41-Monitor`
- **Пароль:** `12345678`
- **Адрес:** http://192.168.4.1

Через вкладку «Wi-Fi» введите данные домашней сети и нажмите «Сохранить» — устройство
перезагрузится и подключится к ней.

## MQTT

Настраивается на вкладке «MQTT» веб-интерфейса или хранится в NVS.

Публикуемый JSON в указанный топик (по умолчанию `scd41_zal/sensors`):

```json
{
  "co2": 812,
  "temperature": 23.4,
  "humidity": 41.2,
  "timestamp": 123456
}
```

`timestamp` — значение `millis()` на момент публикации (не реальное время).
Интервал публикации — 10 секунд.

## HTTP API

| Метод | Путь | Описание |
|-------|------|----------|
| GET   | `/` | Веб-интерфейс |
| GET   | `/api/data` | Текущие показания и статусы |
| GET   | `/api/wifi/info` | Информация о Wi-Fi (режим, IP, RSSI) |
| POST  | `/api/wifi/config` | Сохранение Wi-Fi (`{"ssid":"...","password":"..."}`) и перезагрузка |
| GET   | `/api/mqtt/config` | Текущие настройки MQTT |
| POST  | `/api/mqtt/config` | Сохранение настроек MQTT и перезагрузка |
| GET   | `/api/sensor/info` | Наличие датчика, серийный номер, состояние ASC |
| POST  | `/api/calibration/asc` | Вкл/выкл ASC (`{"enabled":true}`) |
| POST  | `/api/calibration/fresh_air` | Калибровка свежим воздухом (400 ppm) |
| POST  | `/api/calibration/force` | Принудительная калибровка (`{"value":400..2000}`) |
| POST  | `/api/calibration/factory_reset` | Заводской сброс датчика |
| POST  | `/api/sensor/restart` | Перезапуск периодических измерений |

## Калибровка

- **ASC** (автоматическая самокалибровка) включена по умолчанию. Требует периодического
  пребывания датчика в атмосфере ~400 ppm (свежий воздух) в течение нескольких дней.
- **Калибровка свежим воздухом**: поместите датчик в свежий воздух (~400 ppm) и запустите.
- **Принудительная калибровка (FRC)**: укажите известную концентрацию CO₂ (400–2000 ppm).
- Команды калибровки выполняются только в режиме *idle*: перед ними периодические
  измерения останавливаются, после — возобновляются (см. `sensorIdle()` / `sensorResume()`).
